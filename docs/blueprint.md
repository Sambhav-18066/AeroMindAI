# **App Name**: AeroMind AI

## Core Features:

- AI Conversation System: Real-time AI conversation with streaming responses, microphone input (STT), and text-to-speech output (TTS). Utilizes session context tracking and session memory to maintain conversational flow.
- Selectable AI Personalities: Offers multiple AI personalities (Teacher, Mentor, Friend, etc.), each modifying response tone, vocabulary, questioning style, TTS voice, and emotional tone.
- Voice Features (STT + TTS): Implements Speech-to-Text (STT) to convert user voice to text in real-time, and Text-to-Speech (TTS) for AI responses with adjustable speed, pitch, and optional emotional variants.
- Aero-Themed UI: Applies a Windows 7 Aero Glass aesthetic with transparent glass backgrounds, high blur, glow borders, soft reflections, subtle gradients, floating glass bubbles, and light particles. Includes Light and Dark Modes with specific color schemes.
- Analytics Engine: Analyzes each session for Words Per Minute (WPM), lexical richness, pause length, response latency, autobiographical depth score, narrative continuity score, AI vs User talk ratio, and sentiment analysis.
- Session Summary Generation: Generates a summary of each conversation: what the user and the AI focused on, strengths, weaknesses, personalised improvement suggestions, suggested next topics, and a confidence rating.
- Firestore Integration: Utilizes Firestore to store user profiles, session metadata, message history, analytics, and AI-generated summaries.

## Style Guidelines:

- Primary color: Soft cyan (#76D9FF), inspired by the Windows Aero aesthetic, offering a sense of calmness and clarity.
- Background color: Light grey-blue (#E5F6FF) in Light Mode, desaturated to provide a frosted glass effect. In Dark Mode, a near-black (#121212) for a Midnight Aero feel.
- Accent color: Electric purple (#BE76FF) for interactive elements and highlights, providing a neon glow in Dark Mode.
- Body and headline font: 'Inter' sans-serif for a modern, machined feel, and easy readability.
- Use translucent glass icons with soft glows and subtle animations for a modern Aero look.
- Design the UI with transparent glass panels, soft shadows, and floating elements to mimic the Aero Glass aesthetic. Use blur effects to create depth.
- Incorporate smooth transitions and subtle animations, like floating particles and glowing edges, to enhance the user experience and match the Aero theme.
